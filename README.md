# 🎯 Routineify - Habit Tracker

A dynamic habit tracker web application developed for the ICT 1209 Mini Project at Rajarata University of Sri Lanka.

## 🚀 Live Demo
Click here to view Live Site:-https://indun-art.github.io/routineify-habit-tracker/

## ✨ Features
- Add and Delete daily habits dynamically
- Interactive habit completion status
- User authentication screens (Login, Signup, Reset Password)
- Analytics and Dashboard(member & admin) views

## 🛠️ Tech Stack
- HTML5 & CSS3
- Bootstrap 5
- JavaScript
